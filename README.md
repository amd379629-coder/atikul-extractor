How to run this tool:

1. Update packages and install Git & Python:
   pkg update && pkg install git python -y

2. Clone the repository:
   git clone https://github.com/amd379629-coder/atikul-extractor.git

3. Navigate to the project directory:
   cd atikul-extractor

4. Run the tool:
   python3 site_source.atikul_extractor.py
